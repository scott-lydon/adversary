How to get a task token for this target

The sidecar at {{ target.base_url }}/chat requires a real HS256 JWT signed with the deployment's COPILOT_BFF_JWT_SIGNING_KEY. Three honest paths, easiest first:

Recommended (one shell command)

Run this from your terminal. It SSHs to the host, mints a token inside the BFF container (so the signing key never leaves the deployment), prints the token to stdout: 

adversary debug mint-task-token \
  --remote-host root@5.161.253.237 \
  --bff-container copilot-bff \
  --user-id admin \
  --patient-id Patient/87413 \
  --ttl-seconds 1800

Verified end-to-end against this exact target: the resulting JWT returns HTTP 200 from POST /chat. Paste the token into the Task token field below.

Other paths if SSH is not available:

  1. Capture from a live browser. Log into OpenEMR with admin / OpenEmrAdmin!2026, click Launch Co-Pilot on Patient/87413, open Chrome DevTools → Network tab, watch a /chat request fire, copy the Authorization: Bearer <token> header value. TTL is 5 minutes.
  2. Local mint with a known key. If you exported the signing key into your shell already: 
    COPILOT_BFF_JWT_SIGNING_KEY='<value>' adversary debug mint-task-token \
  --user-id admin --patient-id Patient/87413 --ttl-seconds 1800
  3. Local dev sidecar. Run the sidecar locally (COPILOT_BFF_JWT_SIGNING_KEY=<dev-key> python -m sidecar.main), register a fresh http_chat target at http://127.0.0.1:8801, mint a token with the same dev key, scan that.

The minter produces a real HS256 JWT shaped exactly like your BFF's mint_task_token (iss, sub, patient_id, purpose_of_use, scope, iat, nbf, exp, jti). The sidecar's verify_task_token accepts it as long as the signing key matches. Pass --synthetic for an offline placeholder (NOT accepted by any real sidecar).
