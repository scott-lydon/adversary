Step 1 · How to get a task token

You can't avoid this step: scanning {{ target.base_url }}/chat requires a real HS256 JWT signed with the deployment's COPILOT_BFF_JWT_SIGNING_KEY. The sidecar's verify_task_token rejects anything else. Three honest paths, easiest first.

Recommended · one shell command

From a terminal on the machine that runs this dashboard. SSHs to the host, mints a token inside the BFF container (signing key never leaves the deployment), prints the JWT to stdout: 

adversary debug mint-task-token \
  --remote-host root@5.161.253.237 \
  --bff-container copilot-bff \
  --user-id admin \
  --patient-id Patient/87413 \
  --ttl-seconds 1800

Verified end-to-end against this exact target: POST /chat with the resulting JWT returns HTTP 200 with real clinical reasoning in the body. Copy the line of output and paste into the Task token field in the form below. Replace root@5.161.253.237 and copilot-bff for your own deployment.

Fallback A · capture from a live browser session

Use this when SSH to the deployment isn't available to you.

  1. Open {{ target.base_url }} in Chrome; log in with admin / OpenEmrAdmin!2026.
  2. Open Patient/87413's chart.
  3. Click Launch Co-Pilot in the action bar.
  4. Open Chrome DevTools (Cmd-Option-I); select the Network tab.
  5. In the Co-Pilot UI pick a patient + purpose and click Run. Watch a request to /chat appear.
  6. Click that request, scroll to Request Headers, copy the value after Authorization: Bearer .
  7. Paste into the Task token field. TTL is 5 minutes.
Fallback B · local mint when the key is already in your shell

If COPILOT_BFF_JWT_SIGNING_KEY is already exported:

COPILOT_BFF_JWT_SIGNING_KEY='<value>' adversary debug mint-task-token \
  --user-id admin --patient-id Patient/87413 --ttl-seconds 1800

The minter produces a real HS256 JWT shaped exactly like the BFF's mint_task_token (claims: iss, sub, patient_id, purpose_of_use, scope, iat, nbf, exp, jti). The sidecar's verify_task_token accepts it as long as the signing key matches. Pass --synthetic for an offline placeholder that does NOT validate against any real sidecar.
